# Marvin Ken Tumando — Professional CV & Portfolio

## Project Title
Marvin Ken Tumando — Professional CV & Portfolio

## Short Description
An interactive, AI-themed dual-theme (Terminal Dark vs. Editorial Light) Curriculum Vitae and web portfolio. It features executive summaries, vital statistics, filterable experience ledgers (highlighting your editorial leadership at *The Davao Reef* and *The Shoreline*), skill proficiency matrices, project deep-dive modals, and a contact inquiry chat simulation.
